# Лабораторна робота 3.4 - варіант 8

Тема: створення та використання делегатів, подій і лямбда-виразів.

## Опис проєкту

Консольний застосунок демонструє роботу делегатів і подій у C# на прикладі завдань варіанта 8.

У першій частині програма перетворює двовимірний масив на одновимірний масив сум його рядків. Одна й та сама операція викликається через власний делегат двома способами: за допомогою анонімного методу та лямбда-виразу.

У другій частині моделюється банківський рахунок. Його можна поповнювати, знімати кошти в межах дозволеного овердрафту та закривати при нульовому балансі. Якщо операція перевищує кредитний ліміт, рахунок генерує подію, а окремий клас-обробник виводить повідомлення користувачеві.

## Структура

- `Program.cs` - демонстрація роботи програми.
- `RowSumCalculator.cs` - делегат і обчислення сум рядків матриці.
- `BankAccount.cs` - модель банківського рахунку та подія.
- `CreditLimitExceededEventArgs.cs` - аргументи події.
- `BankAccountEventHandler.cs` - обробник події.

## Виконані вимоги

- Суми елементів рядків двовимірного масиву отримуються через делегат.
- Реалізовані і анонімний метод, і лямбда-вираз.
- `BankAccount` підтримує відкриття, поповнення, зняття коштів з овердрафтом і закриття рахунку.
- `CreditLimitExceededEventArgs` передає дані про перевищення кредитного ліміту.
- `BankAccount` містить подію та метод, який її генерує.
- `BankAccountEventHandler` містить обробник зі стандартною сигнатурою .NET.

## Запуск

```bash
dotnet run --project Lab4/Lab4.csproj
```

Очікувані суми для демонстраційної матриці: `[6, 15, 24]`. Під час спроби перевищити кредитний ліміт операція відхиляється та виводиться повідомлення про подію.

## Контрольні запитання

1. **Що таке делегат?** Типобезпечне посилання на один або кілька методів із певною сигнатурою.
2. **Приклад делегата.** `RowSumsOperation operation = RowSumCalculator.Calculate; int[] result = operation(matrix);`.
3. **Склад класу делегата.** Посилання на об'єкт, посилання на метод та список викликів для мультиадресного делегата.
4. **Контроль типів.** Компілятор перевіряє, чи збігаються типи параметрів і результату методу із сигнатурою делегата.
5. **У що розгортається делегат?** У клас, похідний від `MulticastDelegate`, який зберігає цільовий об'єкт, адресу методу та список викликів.
6. **Що таке анонімний метод?** Метод без імені, який оголошують через слово `delegate` і присвоюють змінній делегата.
7. **Що таке лямбда-вираз?** Короткий запис анонімної функції, наприклад `x => x * 2`.
8. **Побічні ефекти.** Анонімні методи й лямбди можуть захоплювати зовнішні змінні та змінювати їх, тому результат залежатиме від зовнішнього стану і часу виклику.
9. **Приклад події.** `public event EventHandler<CreditLimitExceededEventArgs>? CreditLimitExceeded;`.
10. **Генерування події.** Клас-власник викликає делегат події, зазвичай у захищеному методі `On...`.
11. **Підписка і відписка.** Оператори `+=` та `-=` додають і видаляють метод-обробник.
12. **Мультиадресний делегат.** Він зберігає кілька методів і викликає їх послідовно в порядку додавання.
13. **Різниця між делегатом і подією.** Делегат можна викликати напряму, а подію може генерувати лише клас, у якому її оголошено.
